# AI Handwritten Character Recognition

## Description
A Deep Learning web application that recognizes handwritten English alphabet characters (A–Z) using a Convolutional Neural Network (CNN).

## Features
- Draw characters on canvas
- Upload character images
- Predict A–Z alphabets
- Display confidence score
- Interactive Streamlit interface

## Technologies Used
- Python
- TensorFlow
- Streamlit
- NumPy
- Pandas
- Plotly

## Dataset
A-Z Handwritten Alphabets Dataset

## How to Run

### Train Model
```bash
python train_model.py
```

### Run Application
```bash
streamlit run app.py
```

## Result
- Character Recognition (A–Z)
- Accuracy: ~99%
